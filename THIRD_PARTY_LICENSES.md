## Windows x64 runtime inventory

The Windows package contains exactly these six DLLs: `SDL2.dll`, `SDL2_mixer.dll`, `libz.dll`, `libc++.dll`, `libunwind.dll` and `libwinpthread-1.dll`. The final verifier compares this list with the actual ZIP. SDL2 is 2.32.10, Windows SDL2_mixer is 2.8.2, and zlib is 1.3.2. The LLVM license below covers libc++ and libunwind; the MinGW-w64 and winpthreads notices below cover their runtime components.

## SDL2_mixer codec evidence

The import table of the Windows SDL2_mixer.dll lists SDL2.dll, KERNEL32.dll, msvcrt.dll and WINMM.dll. The optional decoders libxmp, Game_Music_Emu, WavPack and Opus are not built in: SDL2_mixer.dll only names them as separate libraries to load at run time (`libxmp.dll`, `libgme.dll`, `libwavpack-1.dll`, `libopusfile-0.dll`), and H12 does not ship these files. The Android libSDL2_mixer.so contains no libxmp, Game_Music_Emu or WavPack code and no Opus decoder.

On both platforms SDL2_mixer has these decoders from its own source tree built in: dr_flac (FLAC), minimp3 (MP3), stb_vorbis (Ogg Vorbis) and TiMidity (MIDI). The Windows build also plays MIDI through the Windows MIDI interface (SDL_mixer native_midi, zlib-style notice by Florian Schulze). The decoder license texts below are copied verbatim from the official SDL2_mixer 2.8.2 release archive (`SDL2_mixer-2.8.2.tar.gz`, SHA-256 `938dff531d00ace2296557a6599abe6f34599e2f34f0a4a08a397e2ccac8b8f7`); the same files are byte-identical in the 2.8.1 archive (SHA-256 `cb760211b056bfe44f4a1e180cc7cb201137e4d1572f2002cc1be728efd22660`). The stb_vorbis text is lines 5815-5853 of `src/codecs/stb_vorbis/stb_vorbis.h`. SDL_mixer's TiMidity files carry the notice "Copyright (C) 1995 Tuukka Toivonen" and state that they may be redistributed under the terms of the Perl Artistic License, reproduced below.

The full SDL2_mixer license is reproduced below as well.
